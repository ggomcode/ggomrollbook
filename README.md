# ggomrollbook 📚

고등학교 3학년 선택교육과정 **이동수업 출석부(1~12반)** 및 **원적학급 출석부(1~11반)** 생성·인쇄 & **월별 예상 급식 캘린더** 시스템입니다.

---

## 🌟 주요 기능

1. **이동수업 출석부 (1~12반 교실 비치용)**:
   - **A4 가로(15mm 여백) 1일 2페이지** 인쇄
   - **1페이지 (오전)**: 1~4교시 **4단(Columns) 레이아웃**
   - **2페이지 (오후)**: 5~7교시 레이아웃 (수요일 5·6교시는 '창의적 체험활동' 자동 표기)
   - 각 교시 단 하단에 **`예상 출석 인원`** 자동 집계
   - 교실당 주 10장으로 1주일 출석부 완결

2. **원적학급 주간 출석부 (1~11반 담임/학급용)**:
   - **A4 가로(15mm 여백) 1면 1주일(월~금)** 인쇄
   - 요일별 `조`, `1`, `2`, `3`, `4`, `5`, `6`, `종` (수요일 5·6교시 '창') 42칸 컬럼
   - 재적 학생 학번순 정렬

3. **월별 예상 급식 인원 캘린더 (영양사실/급식실용)**:
   - **A4 가로 1면 1달** 캘린더 인쇄 (2026년 9월 ~ 2027년 1월)
   - 일자별 공휴일/학사 행사 표시 및 **일일 예상 급식 인원** 산출
   - 월간 총 급식 일수, 총 예상 식수, 일평균 식수 요약

4. **학생·시간표 실시간 검색 (교무실/상담실용)**:
   - 학생 이름 또는 학번 검색 시 1초 만에 요일별 교시·교실·담당교사 시간표 조회

5. **구글 스프레드시트 실시간 연동 및 안전성**:
   - `출결사항` 시트 (GID: 923106420): 학생 338명 기본 정보, 요일별 출결(질병, 미인정, 중식여부), 시간표
   - `행사및휴일` 시트 (GID: 969683114): 공휴일, 정기고사, 단축수업(교시 미실시), 시간표 변경(Swap) 자동 반영
   - P열 학적 특이사항 자동 반영:
     - `특수`: '특' 표기 (10% 음영), 급식 포함 (X 제외)
     - `파스`: '파' 표기 (10% 음영), 급식 포함 (X 제외)
     - `순회`: '순' 표기 (10% 음영), 급식 제외
     - `자퇴` / `위탁` / `전출`: 행 전체 50% 어두운 음영 처리, 급식 제외
   - 오프라인 기본 데이터 내장으로 인터넷 연결 없이도 즉시 실행 가능

## 🚀 로컬 실행 방법

Python이 설치된 환경에서 다음 명령어로 로컬 웹 서버를 실행합니다:

```bash
# 로컬 서버 실행 (포트 3000)
py -m http.server 3000
```

브라우저에서 `http://localhost:3000`으로 접속합니다.
