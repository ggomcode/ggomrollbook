# ggomrollbook 📚

고등학교 3학년 선택교육과정 **이동수업 출석부(1~12반)** 및 **원적학급 출석부(1~11반)** 생성·인쇄 & **월별 예상 급식 캘린더** 시스템입니다.

---

## 🌟 주요 기능

1. **이동수업 출석부 (1~12반 교실 비치용)**:
   - **A4 가로(10~15mm 여백) 1일 2페이지** 인쇄
   - **1페이지 (오전)**: 1~4교시 **4단(Columns) 레이아웃** (A4 가로 1면 정밀 핏)
   - **2페이지 (오후)**: 5~7교시 레이아웃 (수요일 5·6교시는 '창의적 체험활동' 자동 표기)
   - 각 교시 단 하단에 **`예상 출석 인원`** 및 **세부 출결 통계(출석인정(생결), 출석인정(체험), 질병, 기타, 미인정)** 2열 컴팩트 그리드 자동 집계
   - 교실당 주 10장으로 1주일 출석부 완결

2. **원적학급 주간 출석부 (1~11반 담임/학급용)**:
   - **A4 가로(15mm 여백) 1면 1주일(월~금)** 인쇄
   - 요일별 `조`, `1`, `2`, `3`, `4`, `5`, `6`, `종` (수요일 5·6교시 '창') 42칸 컬럼
   - 재적 학생 학번순 정렬

3. **월별 예상 급식 인원 캘린더 (영양사실/급식실용)**:
   - **A4 가로 1면 1달** 캘린더 인쇄 (2026년 9월 ~ 2027년 1월)
   - 일자별 공휴일/학사 행사 표시 및 **일일 예상 급식 인원** 산출
   - 월간 총 급식 일수, 총 예상 식수, 일평균 식수 요약

4. **학생·시간표 실시간 검색 (교무실/상담실용)**:
   - 학생 이름, 학번 또는 **교사명** 검색 시 1초 만에 요일별 교시·교실·담당교사 시간표 조회

5. **구글 스프레드시트 실시간 연동 및 안전성**:
   - `출결사항` 시트 (GID: 923106420): 학생 338명 기본 정보, 요일별 출결(질병, 미인정, 중식여부), 시간표
   - `행사및휴일` 시트 (GID: 969683114): 공휴일, 정기고사, 단축수업(교시 미실시), 시간표 변경(Swap) 자동 반영
   - P열 학적 특이사항 자동 반영:
     - `특수`: '특' 표기 (10% 음영), 급식 포함 (X 제외)
     - `파스`: '파' 표기 (10% 음영, 9/22~11/17 운영 기간 한정), 급식 포함 (X 제외)
     - `순회`: '순' 표기 (10% 음영), 급식 제외
     - `자퇴` / `위탁` / `전출`: 행 전체 50% 어두운 음영 처리, 급식 제외
   - 오프라인 기본 데이터 내장으로 인터넷 연결 없이도 즉시 실행 가능

## ✨ v2.0 개선 사항

- **🕐 현재 주차/월 자동 감지**: 앱 실행 시 오늘 날짜 기반으로 해당 주차·월 자동 선택
- **🔗 URL 상태 관리**: `#v=moving&w=8` 형태로 현재 뷰/설정이 URL에 반영 (링크 공유 가능)
- **📄 인쇄 확인 다이얼로그**: 인쇄 전 선택 사항과 예상 매수를 미리 보여주고 확인
- **🕰️ 인쇄 타임스탬프**: 출력물에 인쇄 일시 자동 표기
- **🐛 이벤트 리스너 누수 수정**: AbortController 기반 리스너 관리로 성능 안정화
- **🛡️ XSS 방지**: 모든 사용자 데이터에 HTML 이스케이프 적용
- **📐 인쇄 레이아웃 최적화**: 행 분리 방지, 원적학급 42칸 컬럼 글꼴 최적화
- **⚙️ 설정 분리**: 학기 시작일, 교시 수 등이 `AcademicConfig`으로 분리되어 내년 재사용 용이

## 🚀 로컬 실행 방법

Python이 설치된 환경에서 다음 명령어로 로컬 웹 서버를 실행합니다:

```bash
# 로컬 서버 실행 (포트 3000)
py -m http.server 3000
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## ⚙️ 연도별 설정 변경

[`js/models.js`](js/models.js) 상단의 `AcademicConfig` 객체만 수정하면 새 학년도에 바로 사용할 수 있습니다:

```javascript
export const AcademicConfig = {
  semesterStartDate: new Date(2027, 8, 20),  // 새 학기 시작 월요일
  startWeekNum: 6,
  endWeekNum: 21,
  graduationDate: '2028-01-05',
  // ...
};
```
